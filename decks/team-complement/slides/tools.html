SOLUTION 02 ／ 便利な型

凸凹を読める状態にする、三つの型

  1. キックオフ

    ドラッカーエクササイズ

    1. 自分は何が得意か
    2. どうやって貢献するか
    3. 何を大切にしているか
    4. 周りは自分にどんな成果を期待していると思うか

    4問に答えて、たがいに共有する。このあとのワークで使う。

  2. 日常

    自分の取扱説明書

    1. 得意なこと
    2. 苦手なこと
    3. 頼り方
    4. 地雷

    1枚に書いて、チームで共有する。

  3. 振り返り

    KPT

    1. Keep　続けたいこと
    2. Problem　問題
    3. Try　次に試すこと

    Keepに「誰の凸に助けられたか」も書く。申告した凸凹と、実際に見えた凸凹のずれが、自分を知る材料になる。
