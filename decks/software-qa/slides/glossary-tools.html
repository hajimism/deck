用語意味用語意味
ユニットテスト関数や部品を1つずつ切り離して確かめるテストVitestJavaScript・TypeScript のテストを実行する道具
コンポーネントテスト画面の部品を描画し、操作して確かめるテストTesting Libraryロールやラベルなど、利用者に見えるもので要素を取るテストの道具
結合テスト部品どうしや、API とのつながりを確かめるテストStorybook画面の部品を、状態ごとに表示して確かめる道具。1つの状態を Story と呼ぶ
E2E テスト画面を通して、最初から最後まで操作するテストPlaywrightブラウザを自動で操作する道具。E2E テストや画面の撮影に使う
見た目の回帰テスト（VRT）画面を撮影して前回と比べ、意図しない見た目の変化を見つけるテストMSWアプリの通信をその場で差し替え、決まった応答を返す道具
契約テストAPI を出す側と使う側が、やりとりの形の約束を守っているかを確かめるテストfast-checkランダムな入力を大量に作って、性質が成り立つかを試す道具
モックテストのために、本物の API などの代わりに置く偽物StrykerJavaScript でミューテーションテストを行う道具
lintコードの書き方の誤りや規約違反を自動で指摘する道具（ESLint、Biome など）axeアクセシビリティの違反を自動で検出する道具
型（TypeScript）値の形をあらかじめ決め、違う形の値を使うとエラーにする仕組みLighthouse CIページの速さなどを自動で計測し、基準を下回ったら知らせる仕組み
判別可能 union共通の項目の値で、どの形かを区別できる型。ありえない状態を書けなくできるフェイクタイマーテストの中で、時計を止めたり進めたりできる仕組み
CI変更のたびに、ビルドやテストを自動で回す仕組みlockfileインストールする依存パッケージの版を固定したファイル
PR（プルリクエスト）変更を本体に取り込む前に、レビューを受ける単位エラートラッキング・RUM本番で起きたエラーを集める仕組みと、実際の利用者の環境で速さを計測すること

注：道具の名前は覚えなくてよい。どの段階で、どんな欠陥を検出する道具かが分かれば足りる
