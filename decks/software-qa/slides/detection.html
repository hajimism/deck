テストの検出力

テストの検出力はカバレッジでは測れないので、わざとコードを壊し、テストが落ちるかどうかで、良いテストと弱いテストを見分ける

確かめたい実装：18歳以上なら登録できる

const canRegister = (age: number) => age >= 18;

わざと壊す>= を > に変える

壊したコード（ミュータント）

const canRegister = (age: number) => age > 18;

同じミュータントを当てると、弱いテストと良いテストを見分けられる

弱いテスト：30歳でしか試していない

expect(canRegister(30)).toBe(true);

壊したコードでも通ってしまう。カバレッジは 100%

ミュータントが生き残った。このテストは、境界の欠陥を検出できない

良いテスト：境界の18歳と17歳を確かめる

expect(canRegister(18)).toBe(true);
expect(canRegister(17)).toBe(false);

壊したコードで落ちる

ミュータントを検出した。このテストは、境界の欠陥を検出できる

テストの良し悪しは、壊したコードで落ちるかで判定する（ミューテーションテスト）。カバレッジは、コードが実行されたことしか示さない

用語：Stryker＝JavaScript でミューテーションテストを行う道具。ミュータントを検出する（kill）＝壊したコードでテストが落ちること

注：実際の欠陥357件での研究では、ミュータントを検出する力は、実際の欠陥を検出する力と相関し、カバレッジとは独立だった。全体の点数を目標にせず、変更した部分で生き残ったミュータントを見る

出所：Just ら, “Are Mutants a Valid Substitute for Real Faults in Software Testing?”, FSE 2014
