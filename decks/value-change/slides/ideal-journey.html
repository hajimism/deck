価値を構想する ／ 理想のジャーニー

理想のジャーニーを描くと、やることが決まる

After が描けたら、ジャーニーマップにする。上司の週次報告で、今と理想を並べてみる。

今

  1. 資料を開く
  2. 数字を探すイライラ
  3. 前週と比べるExcelを開く
  4. 質問する
  5. 指示する

理想

  1. 資料を開く
  2. 1枚目で前週比と異常値が目に入る
  3. 聞きたいことが補足に書いてある
  4. そのまま指示に移る

理想から、作業が自動的に決まる

  • 11枚目にサマリを置く
  • 2前週比の列を足す
  • 3想定質問に先回りして補足する

作業から考えると「何を足せばいいか」で迷う。After から考えると、迷わない。
